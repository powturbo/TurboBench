# ACEAPEX 2.5.0 — 2026-10-28

The fast profile (levels 11-18, `docs/FORMAT_FAST.md`) gets a new level-11 encoder and a faster decoder. The format is
unchanged: 2.4.x and 2.5.0 read each other's archives.

- **Level 11 encoder** (sparse probe): 25.8 -> ~575 MB/s on one core, silesia 61.38 % (2.4.2: 61.35 %), enwik8 82.7 %
  (2.4.2: 96.8 %). Probes every 3 bytes, every 2nd position in a one-slot hash table, backward extension; matches of
  65..128 bytes are written as tokens of <= 64 bytes.
- **Decoder** (every reader: C++, C99, Python): no length branches on the fast path, no memcpy calls on the escape path;
  on x86-64 Linux an AVX2 clone chosen at load time, so builds without `-march` (lzbench, packages) use 32-byte moves.
- **lzbench on Zen 5** (EPYC 9B45, silesia.tar, one core, median of 5): aceapex_fast -1 61.38 %, 575 / 15950 MB/s;
  zxc 0.15.0 -1 61.67 %, 852 / 11027 MB/s (`results/zen5-lzbench2-2026-10-28.log`).
- Checked: HEAD judge, portability gate (MinGW-w64, gcc 10, ARMv5), fast-profile API / fuzz / C99 / fixtures, CI.
