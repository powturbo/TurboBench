ВЫВОД: aceapex_depth d НЕ масштабируется потоками — плоско ~330-388 MB/s.
Причина: MEMORY-BOUND (CPU 5%, RAM 83%/146GB). Декод в ОДИН общий буфер 50GB,
потоки конкурируют за память, не за вычисления. Ядра простаивают.
ПРОТИВОРЕЧИЕ РАЗРЕШЕНО: рекорд 11 GB/s (lzbench) — это block-parallel режим
(независимые блоки в отдельные буферы, scaling работает). depth d — один буфер,
memory-bound, scaling мёртв. РАЗНЫЕ режимы одного кода.
СЛЕДСТВИЕ для GPU+CPU гетеродекода: нужен block-parallel CPU-путь (lzbench-стиль,
11 GB/s), тогда GPU 165 + CPU 11 = +6.7% И CPU добивает overflow за VRAM-лимит.
Через depth d (memory-bound) гетеродекод смысла не имеет.
