## 3. Архитектурный ход v3: «декод без разбора» (parse-free tokens)

Наш уникальный актив — абсолютные смещения и независимые блоки 16 КиБ: адрес назначения каждого
байта определяется суммой длин до него. Сегодня эта сумма считается последовательно внутри
разбора. v3 делает её **префиксной суммой по вектору токенов фиксированной ширины**:

1. **Токен фиксированной ширины**, последовательность «литералы + матч» в одном токене
   (как LZ4/misa77, а не отдельные команды): u32 = litlen | mlen | dist (14 бит хватает внутри
   блока 16 КиБ); длинные длины — в боковом потоке; rep-коды заменяются флагом «dist = прежний».
2. **Декод в два шага, оба векторные**: (а) SIMD/warp-скан литлен+млен → позиции вывода и
   литералов для 8 (AVX2) / 16 (AVX-512) / 32 (warp) токенов сразу; (б) копии: литералы и матчи
   с dist ≥ 16 — независимые широкие копии; dist < 16 — периодическая заливка (уже есть).
   Ветвления по типу команды нет; на GPU warp обрабатывает 32 токена параллельно вместо одного.
3. **Плотность сохраняется энтропией на байтовых плоскостях токенов**: 4 плоскости u32 через
   имеющийся 32-lane rANS (ADR-018, AVX2) или zstd — токены декодируются пачкой в массив,
   который и есть вход шага (а). Литералы: как сейчас (zstd/Huffman для текста, open-пак для ДНК).
4. **Ограничения формата ради декодера** (доказаны misa77): потолок одной копии матча и
   минимальная дистанция для безусловной широкой копии задаются кодером; кодер l1 (ADR-020)
   уже ищет матчи ≥ 32 на ДНК.

Внешнее подтверждение приёмов: misa77 (два потока + спекулятивный разбор, 7813 MB/s 1T),
zxc -7 (Huffman только на литералах, 33.1 % на M2 при 5054 MB/s), GDeflate (32-way interleave),
наш composition-scan rep-цепи (1.61x на H100, 0 расхождений, C-019).

Почему это отрыв, а не догонялки: ни у zxc, ни у misa77, ни у kanzi нет одновременно (а)
независимых блоков 16 КиБ с регионом 50 мкс, (б) одного формата для CPU и GPU, (в) плотности
генома выше zstd -19. v3 добавляет к этому однопоточную скорость класса misa77 и снимает
последовательный разбор на GPU — главный оставшийся тормоз.
